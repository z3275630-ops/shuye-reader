# 按症状排查

先核对版本，再查原因；同一个症状可能有多个来源，不能仅凭表格断定。下面区分已经修复的历史问题、源码确认的缺口与尚待复现的后果。功能范围见 [功能对照](report-coverage.md)，本版证据见 [0.3.10 验证](verification-0.3.10.md)。本表参考协助 PR #54，经主 Agent 校正，不照搬所有“真因”断言。

## 0.3.10 常见变化

- 配色只在预览变化：旧版 reader.theme 未接全应用，mist 还缺反序列化白名单；已统一为默认联动。需要恢复标准配色时在排版中选择 Claude / 海雾 / 夜读，显式选择会清除正文自定义颜色。
- 正文太大或太松：旧默认迁移为 18 / 1.65，个人非默认设置保留；可用“使用 Claude 正文间距”重设排版。系统大字设置仍生效。
- 上下工具栏一直占位：点按正文中央隐藏 / 唤回；Android 系统栏已使用原生接口，当前仍需手机核验。
- 空热力图像没画：零记录方格已加深，半年 / 全年仍可左右滑动。下方时长图按真实日期与分钟显示；常读时间没有记录时只显示说明。
- 换封面 / 均衡器 / 原生设置无反馈：#56 / #58 / #59 已加异常提示与异步存活保护；PDF 离开后延迟页码回调 #57 已跳过。

## 书库、备份与导入

| 症状 | 定位与当前状态 |
| --- | --- |
| 升级书库时反复失败 | #2 / #34 待修：单本迁移失败与整库快照超过 restore 80 MB 门槛是不同路径。失败保留旧库，不能承诺当前已有可操作的恢复入口；本版未改 Android 加密迁移。 |
| 迁移恢复文件长期占空间 | #50 待修：`repository.dart` 写入加密恢复快照，目前未找到应用读取 / 清理入口。与 #7 的恢复点流程一起设计，不能无条件删掉可能需要的恢复材料。 |
| 恢复后设置又变旧 | #51 已让云盘与工具箱本地恢复刷新同一 ReaderSettings 对象及全应用主题；回归包括加密下载后在同一会话再次保存。 |
| 备份少了未保存的阅读时间 | #52 已先提交活跃正文 / PDF 秒数并排空计时队列；恢复事务期间暂停记录，成功后旧阅读页不写回。自动回退点和低内存迁移仍待做。 |
| 设置损坏后首页空白 | #3 已保存原设置副本并恢复默认，书籍和笔记保留。隐私原状态无法确认时先锁住书库并说明原因；解锁后可继续使用，不清库。 |
| 文本导入变乱码 | #35 待修：严格 UTF-8 失败后整本按 GBK。PR #42 的低错误率修复也会损坏合法 GBK，详见衔接表；计划保留来源并让编码可确认。 |
| EPUB 书名或正文含替换字符 | #46 待修：EPUB 的 read 无条件宽松 UTF-8，未处理 XML 编码声明。非 UTF-8 输入会静默损坏；不要据此宣称所有 GBK EPUB 都符合规范或一律猜编码导入。 |
| 中文 RTF 成为拉丁字符 | #48 待修：十六进制转义逐字节转字符，缺少 ansicpg 与字节序列解码。需保留 Unicode 控制字语义，不能简单规定所有文件缺省 GBK。 |
| EPUB 缺一章整本导入失败 | #47 待核定容错方式：缺失 spine 文件会让 read 抛错，这是源码现状。静默跳章会产生不完整书籍，需可见缺失清单 / 用户确认；大小写兜底也要处理歧义。 |
| 自定义分章 / 净化后卡住 | #49 待修：现校验限制括号，多个无括号重复片段仍可通过。Dart 回溯正则无内置超时，需安全语法或可中断执行；不要在主线程尝试长恶意输入。 |
| ZIP / CBZ / EPUB 内存突增 | #33 待修：当前展开上限来自可伪造声明大小。锁定 archive 的 IO inflate 先汇总输出，再交 OutputStream，单加预算流不能限制此前分配。需真正逐块限额 / 校验。 |
| 大书导入或备份慢 | #18 待修：PDF / CBZ 等资源及整库快照存在完整内存复制；APK 变小不能证明峰值内存下降。 |
