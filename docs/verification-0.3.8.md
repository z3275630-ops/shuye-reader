## 本轮结果

- 按用户要求统一默认衬线字体，包括标题、正文、按钮、表单、导航、助手、自绘统计 / 人物图与分享模板。加入开源 Noto Serif SC 的静态裁剪资源 Shuye Serif，保留 OFL 许可与应用许可登记，不使用 Anthropic 专有字体。用户导入正文自定义字体仍优先；原版 PDF / 漫画不改源字形。
- 新增 Claude 阅读纸色 `#FAF9F5` / `#22221F`；保留原四纸色、自定义颜色、墨水屏与夜间时间表优先级。正文分页测量、预览和实际绘制统一两端对齐，长行填满宽度，段落 / 页面碎片末行自然留白，不插入字符或修改书籍与笔记。
- 深色文字与 1.9 / 24 线条图标、暖白页面和米灰卡片；调整文字层级，章节名 / 章节计数增至 13dp 并加深。品牌横幅略缩小，白绿原图保留。
- 选择性采纳 PR #24 / Issue #23 的暖白方向、橙色热力图、分享配色与设计入口建议；重复实现不合入，不整体覆盖已完成的设置、助手、深浅主题及阅读方案。

参数与来源见 [风格记录](claude-style.md)，提案决定见 [衔接表](prd/review-2026-10-05.md)，字体覆盖与裁剪见 [字体说明](../assets/fonts/README.md)。

- `aapt` 核对版本 0.3.8 / 2011、包名、API 24 / 36、仅 `arm64-v8a`。`apksigner verify --verbose --print-certs` 通过 v2 签名，证书 SHA-256 与正式旧版一致：`03f258a82e60226f8c9b305a1d1a97f1bd1871ff10f6754fe280a25432dbb8ce`。
