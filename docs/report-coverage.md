# 调研材料逐项对照 · 0.3.4

依据用户提供的《Reeden-1.42.1-技术与架构分析报告》。以下按功能领域覆盖原报告，不把对原 APK 的逆向取证、推测或商业授权服务当作书叶的已实现功能。

“实现”表示代码中有实际入口和行为；原生 / 第三方功能是否经过真实设备或账号测试，另见验证记录。**仍有部分实现和待做项，不等于全部复刻。**

| GPU 翻页 / 纸背 / 书脊 | 正文控制：纸张卷页 shader；双页分栏与书脊 | 视觉模型独立实现；没有还原全部原始 shader |

## 录屏补充

0.3.0 新增可配置首页、分组工具搜索、独立书库分组管理、时段统计、应用外观与分享样式，见 [录屏借鉴记录](video-reference.md)。原录屏、抽帧和原应用界面素材仅用于本机观察，没有进入仓库或安装包。

## 后续工作顺序

先完成原生升级与文件 / PDF / OCR / 音频 / 小组件的设备自动化回归，然后推进复杂 EPUB 结构、完整编辑 / 目录、增量同步与冲突处理，再补齐剩余服务与更细的个性化管理。这份清单明确保留未完成内容，避免把按钮或名称当成可用功能。

0.3.1 将统计页热力图改为周历方格，补全七天标签、月份、七级颜色、每日查询与连续天数，支持往年和辅助功能。Android 桌面热力图组件未在本轮重做。
