# 验证记录 · 0.3.5 · 2026-10-05

## 实现与验证

- 新增共用 LabeledField，标签固定置于控件上方，左边缘对齐，间距 8dp。展示标签排除独立朗读，将字段名称关联到控件语义；不使用边框上的浮动标签。
- 替换共用编辑表单、名称弹窗、两种文本规则、阅读下拉菜单及书架排序，保留控制器、密码隐藏、校验提示和保存行为。搜索提示仍在输入框内。
- `dart format lib test`：43 个文件；`flutter analyze --no-pub` 无问题；完整自动测试 49 项通过，默认跳过 3 项可选预览测试。
- 交互测试覆盖 320px、1.5 倍字号、浅深色；检查标签和输入框左边缘及 8dp 间距、输入前后位置稳定、编辑控件语义名称、输入保存。现有书库、导入、笔记、阅读、备份和热力图测试通过。
- 3 项可选截图测试通过，生成 24 张 Flutter 控件预览；检查浅深色编辑弹窗。使用 Windows 字体渲染，不是安卓真机截图；热力图彩色预览数据仅限测试。
- 正式 ARM64 压缩构建通过，包名 dev.shuye.shuye_reader，版本 0.3.5+8、ARM64 split 版本码 2008，最低 API 24、目标 API 36。正式签名与 ZIP 对齐核验通过。
- 六个 ARM64 库均为 ZIP DEFLATE，ELF LOAD 段至少 16 KB，清单保留 extractNativeLibs=true。除随 Dart 修改变化的 libapp.so，其余五个运行库与上版解压后字节一致；模型、图片、字体及许可资源路径与字节保持。依赖锁文件与上版一致。
- APK 为 **27,336,137 字节，26.07 MiB / 27.34 MB**；比 0.3.4 变化 -892 字节。发布仅一个 APK，另附更新说明与 SHA256SUMS.txt。
- 协作约定和界面说明补充固定标签规范；MIT、贡献指南、PR / Issue 模板等既有材料保留。
