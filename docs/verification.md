## 验证范围

- Flutter 静态分析：无问题。
- 14 项核心自动测试通过，另外执行了 1 项可选界面截图测试并检查 5 张预览。
- 自动测试覆盖：TXT 分章、超长无章文本分段、UTF-8 / UTF-16 / GBK、净化可撤销、EPUB spine 顺序、脚本移除、异常文件、字体缩放分页与 emoji 边界。
- SQLite：内容去重保留旧进度、笔记与记录级联删除、完整备份恢复、无效数据保护与事务回滚、关闭后重新打开持久化、示例不重复补回。
- 界面：阅读翻页、笔记保存、目录、搜索、返回书架续读；320×640 与 600×800 布局。
- 视觉检查：用真实 Flutter widget 渲染书架、阅读、排版、笔记编辑和统计预览，逐张查看。截图使用本机字体，**不是安卓真机截图**。
- 安卓 release 构建：ARM64、ARMv7 与 x86_64；用项目自己的 RSA 3072 位签名库签名。
- 包检查：应用名“书叶”，包名 `dev.shuye.shuye_reader`，最低 API 24，目标 API 36。分架构构建会把版本号编码为 1001 / 2001 / 4001（Flutter 自动规则）。
- `apksigner verify` 验证签名；`aapt2 dump badging` 检查权限、版本与架构。

## 发现并修复的问题

- 默认分章规则含非捕获分组，不能被通用规则检查误拒绝。
- `gbk_codec` 的字节流必须使用 `gbk_bytes` 解码，避免截断双字节中文。
- 分页二分测量时也必须避免截断 UTF-16 代理对，否则部分引擎会错误报告单行高度。
- 小封面用固定设计尺寸缩放，解决继续阅读卡片中的文字溢出。
- 超长无章节 TXT 先生成虚拟分段，避免一次对整本小说进行前台分页。
- Windows 中文路径不兼容：实际英文构建副本、英文 Gradle 缓存与英文临时目录；构建工具依赖使用当前可用的本地代理下载，未修改全局网络设置。
