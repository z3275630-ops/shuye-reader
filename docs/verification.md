## 修复与构建说明

修复了选字手势与翻页冲突、宽屏双页步长、长篇朗读分段、SQLCipher 数据迁移核验、恢复快照后的设置保留、云服务上传协议、MCP 操作检查与前后台关闭、长文本索引和小屏布局等问题。测试中用独立 Navigator 隔离工具页，避免前一页的路由残留干扰结果。

发布构建仅对 ML Kit 未启用的日文 / 韩文 / 天城文可选接口使用精确 R8 忽略规则；中文与拉丁模型已经实际打入包。保留 SQLCipher 原生入口的规则。Windows 构建使用英文副本、任务专用 TEMP / Gradle 缓存与现有本地代理，不修改系统网络设置。
