# 0.3.11 验证 · 2026-10-06

正式版本 **0.3.11+14**，ARM64 版本码 **2014**。用户同意使用协助 Agent 的远端设计稿，本轮先同步 main 的四份 SVG，再将品牌 / 首页方向适配为真实 Flutter 组件。主 Agent 直接推进 main，没有另开 PR。

## 实现与取舍

- 采用 hero SVG 的书页生叶轮廓与 home SVG 的文字加插画布局；三个静态缓存 Path 原生绘制，没有 SVG 运行解析、新增图片、字体、运行依赖或持续动画。
- 首页面板用 22dp 衬线原生标题与 12dp 字幕，真实日期、不增加模拟阅读记录；关闭首页横幅仍保留纯文字标题与日期。窄屏 / 大字让文字与插画上下排列。
- 书架、关于页横幅沿用紧凑 4.2:1 区域，主题表面承载书页插画；设置品牌卡去掉原来的整幅黑色横幅，保留原图标、名称与说明，空间不足时收起小插画。
- Claude、海雾、纸白、青竹浅深主题均使用既有 ColorScheme 的表面、文字与点缀色。原白绿桌面图标 / ShuyeMark 与四份原稿保留，没有新增开屏等待。
- Issue #63 的应用内品牌展示落地，#65 部分采用；App Icon、Splash 与全套空状态没有做。#60–#62、#64、#66–#69 与此前 18 项仍按衔接记录保留，未把设计采纳当作 Bug 修复。

## 未测与升级

本轮没有连接 Android 手机。覆盖安装、设备字形、系统栏、原生 PDF / 音频 / OCR 与真实性能仍待手机回归；预览不证明温度、功耗或帧耗时。包名、签名、递增版本码具备覆盖升级条件，但不能宣称已在手机覆盖安装成功。建议先导出备份，直接覆盖安装，不卸载旧版。音频文件依旧不随 JSON 备份搬迁。
