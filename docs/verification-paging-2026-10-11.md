## 证据与实现

- 新边界回归在原版失败：宽300，向无邻页方向拖120，再反向25，实际位移仍0；修复后反向位移立即25，释放正常提交有效一页。覆盖全书开头 / 末尾两个方向。这是同一次触摸的隐藏位移问题，不能据此归因所有分次末页返回卡顿。
- 新跨原点回归在旧方向判定下失败：左拖100、右拖200、向右释放1000，已显示上一页却撤回；修复后提交上一页。仅反向收手但未越过原点仍撤回，原低速反向回归保留。参考 Legado HorizontalPageDelegate 的跨原点切换方向。
- 新绘制回归在原版失败：纸面外层组件在每次移动时重新创建。改用 Flutter Flow + 绘制通知后，连续拖动及收尾期间保持同一组件树；已有排版 / 绘制计数、预备页面提升及中文字形位置回归继续验证。
- 前后邻章从两个独立的预算改为一个共享队列，轮流推进，输入 / 收尾中暂停备用章，冷加载目标章优先。新增回归检查全局一帧最多一页、无饥饿、暂停 / 必需页优先和失效取消。来源与选择依据见 reader-paging-sources.md。
- 当前章 / 已准备相邻正文来自内存；稳定拖动 / 收尾帧不读取磁盘、重新排正文或启动快照。快速新触摸接管会提交旧页并绑定新远页，仍可能发生首次布局 / 绘制，不能说整个连续手势全程没有创建页面。平移使用保留绘制层；其他淡入 / 仿真仍用原快照路径。进度仅在实际提交后通过已有 SQLite 队列保存，没有全书库 JSON 编码。
