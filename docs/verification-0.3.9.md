# 验证记录 · 0.3.9 · 2026-10-05

版本 **0.3.9+12**，ARM64 split 版本码 **2012**；包名 `dev.shuye.shuye_reader`，最低 API 24 / Android 7.0，目标 API 36。

## 实现结果

- 收紧设置与界面文字：面板标题 20dp / 400、普通标题 22dp / 400、顶栏 18dp / 400、列表 / 控件 15dp、普通文字 14dp、辅助 13dp。默认衬线保留，常用标题不再请求 500/600，不增加字重资源。正文个人字号、导入字体与系统辅助功能保留；原 PDF / 漫画不改源字形。
- 按每个字号保留 Android 非线性 TextScaler，再应用个人缩放倍率；避免采样 scale(1) 后全局线性放大。用户指出的旧阅读控制截图为 320dp / 150% 压力图，本轮默认图 390dp / 100%，大字图独立加 `-large` 后缀。
- 陶土焦点、0.2dp 辅助字距、更小锁图标与轻量摘录空状态；未加入过期时钟、虚构分享序号、私人题记或持续动画。
- 采纳可选海雾界面配色及独立阅读纸色，默认暖白；未知配色回退。分享卡表面跟随配色，暖白细线略加深。既有正文纸色不被界面切换覆盖，数据库与备份格式不变。
- 近七天图来自真实每日秒数，热力图仍在首位；自然日日期、比例柱高、无记录灰线、今日标记与点按详情。演示数据只用于预览。
- 修复夜读选取、页脚小屏大字溢出、搜索切 Tab 后文本与过滤不一致、快速连点叠开阅读器。导航保护覆盖加载与新页首帧，之后保留阅读中的桌面深链接；正文 / PDF 覆盖路由不计时。统计说明与短于 5 秒有效记录计入的现有行为一致。

来源 / 参数见 [风格记录](claude-style.md)，八份协助 PR 的逐项理由见 [衔接表](prd/review-2026-10-05.md)。主 Agent 选择性在 main 实现，未把关闭 PR 说成整体合并。
