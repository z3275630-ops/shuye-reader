`dc6e40d6abae472c3d8a2755f63b8b611c659f9e`。用户反馈 0.3.17 加快后仍偶发卡顿、只有快不够自然，明确要求停止自研收尾参数。

## 实现与来源

- 删除自定义弹簧收尾，直接移植 Readium R2WebView 的 quintic 插值、distanceInfluence 和 smoothScrollTo 时长公式。源码固定提交、版权和 BSD 完整声明保留，APP 开源许可页登记。见[源码记录](reader-paging-sources.md)。
- 参考 Legado / NBReader 整页缓存的处理：当前、前后纸面在拖动前绘制，保留 Flutter 绘制记录；移动只平移纸面。先前仅离屏排版、首次拖动才绘制的处理已替换。没有每帧截图，也不把绘制记录等同 GPU 栅格缓存保证。
- 连续新手势先完成已接受的旧翻页，缓冲输入直到新纸面绑定；旧翻页只提交一次，新手势取消不多提交。保留准备好的 RenderEditable，最多三页。
- 保留已认可字体、配色、源 offset、选字、全屏、设置区、淡入 / 仿真和原有数据行为。未新增依赖、字体或图片，仅新增许可文本及分页公式模块。

## 自动回归

- 16 项阅读专项通过：提前绘制、进入页段落复用、逐行字形和章名 / 页脚位置、连续六次重叠快滑、缓冲时取消不多提交、正文选字和设置裁切。
- 原通用正文查找会把已提前绘制的离屏邻页也算进去。测试改为按实际当前纸面身份验证文本数量与颜色，搜索结果按结果标签验证；没有减少原工作流断言。阅读、笔记、目录、搜索、恢复和双页键盘回归通过。
- 最终格式检查通过；完整测试 133 项通过、10 项可选预览跳过，静态检查无问题。使用独立英文路径副本、锁定依赖及串行测试；旧版测量不算作本版性能数据。测试副本、构建副本与主源码的 lib / pubspec / 新许可文本逐文件一致。
