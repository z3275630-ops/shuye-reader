# 验证记录 · 0.3.7 · 2026-10-05

版本同步为 0.3.7+10，ARM64 split 版本码 2010。包名 `dev.shuye.shuye_reader`，最低 Android 7.0 / API 24，目标 API 36。保留正式签名、压缩原生库与现有数据格式。

## 本轮变化

按用户要求优先 Android APP 的 Claude 风格：学习社区整理的视觉参数，使用已有 Flutter 主题与控件适配，不引入参考项目的架构。来源、字体取舍和实际参数见 [风格记录](claude-style.md)。

- 暖灰 / 炭灰页面、黑白主按钮、灰色选中态、细边线与少量陶土色；共用文字层级、组件圆角和蓝色焦点。锁屏、音频提示、人物关系图遵循浅深主题；书封厚阴影移除，品牌横幅减少高度。
- 阅读控制改为四组卡片，滑杆数值标签支持大字号换行；应用外观预览随缩放更新，书架设置最多预览前三本真实藏书，空库显示提示。
- 助手回答区置于输入卡上方，提示词横向滚动；键盘弹出时收起提示区。原有上下文范围、服务配置、记录和应用前检查流程保留。
- 常用面板使用 Flutter 原生 200ms / 150ms 动效及系统关闭动画设置；按钮使用原生 100ms 颜色反馈。没有新增依赖、图片、字体包、模糊层或持续装饰动画。
