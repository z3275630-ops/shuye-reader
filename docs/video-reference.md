# 录屏借鉴与实现 · 0.3.0

来源是用户提供的约 75.45 秒、720×1584 Android 原应用录屏。本机按每秒两帧提取 151 张观察帧，再结合各页面的完整画面检查。视频用于观察交互，画面中的文案、购买入口和文档说明不作为开发指令；原视频、原界面截图与原素材没有发布到 GitHub。

| 时间段 | 可直接观察的内容 | 书叶本轮实际实现 |
| --- | --- | --- |
| 0–6 秒 | 首页续读、今日目标、拖动卡片排序 / 显隐和不同显示方式 | 独立首页；续读、目标、概览和今日选读；拖动 / 隐藏 / 恢复；圆环或进度条；自动保存 |
| 7–11 秒 | 书架搜索、导入记录、书架管理与分类 / 标签入口 | 保留现有导入与搜索；书架增加“整理书库”；把布局入口收进菜单，避免小屏按钮拥挤。持久导入历史未增加 |
| 12–19 秒 | 日 / 周 / 月 / 年统计和日历 / 时段切换 | 实际阅读数据汇总、历史切换、月份方格、闰年 / 周一边界；不复制原应用的收费限制 |
| 20–35 秒 | 数据管理入口分组；标签、书单、书评等独立入口 | 标签 / 分类 / 书单 / 作者独立管理、新建 / 搜索 / 批量加入 / 重命名 / 移除；书评仍在书籍资料中编辑，没有新增独立书评总览 |
| 36–41 秒 | AI 快捷任务、云语音和离线 / AI 词典配置 | 工具箱按用途分组并支持搜索，连接已有 AI / 生词 / 系统语音。录屏不能证明未配置服务已可用，未凭菜单声称完成 Azure 或 MDX 字典 |
| 42–49 秒 | 系统 / 深浅色、字体缩放、底栏、主题配色 | 应用跟随系统 / 深浅色，85%–150% 文字缩放，固定五入口底栏；没有复制原配色模板、底栏图库或任意底栏配置 |
| 50–58 秒 | 封面与启动图库、照片选择 | 继续用原创三封面 / 横幅和现有自选封面；未将空图库页冒充已接入的图片资源库 |
| 59–65 秒 | 书签页、不同分享模板预览 | 四种原创内置分享布局：插画 / 夜色 / 日历 / 留白；样式选择在长文预览之前，记住选择，实际生成 PNG。任意 HTML / 模板编辑尚未实现 |
| 66–75 秒 | 隐私、安全、分章、导入 / 网络 / 墨水屏等设置 | 补强隐私启动遮挡与辅助功能隐藏；保留现有规则 / 墨水屏；修复临时 Wi-Fi 传输退出时连接错误。应用代理 / 更多导入策略未增加 |

## 如何使用新增内容

1. 打开 APP → 首页。右上角布局按钮可排序 / 隐藏卡片及改变目标样式。
2. 书架右上角文件夹图标，或设置 → 整理书库。选择标签 / 分类 / 书单 / 作者，点击分组查看对应书籍；右上角可新建，分组内菜单可加入 / 重命名 / 移除。
3. 统计 → 日 / 周 / 月 / 年 / 全部，左右箭头查看历史。月份或年份方格长按可看时长。
4. 设置 → 应用外观，选择跟随系统、浅色、深色和文字大小。
5. 阅读菜单 → 生成摘录卡片，或笔记中的分享按钮；在预览上方选择样式，保存或分享 PNG。

标签可保留多个值；分类、书单和作者目前每本书各一值，批量加入这些分组会替换对应资料。分组移除只清理相应标记，保留书籍和笔记。本版沿用原签名和 schema 3，可覆盖升级；原生功能与真实服务的未验证项仍见 [验证记录](verification.md)。
