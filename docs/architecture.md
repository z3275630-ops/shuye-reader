## 数据

Schema 3：`books`、`notes`、`settings`、`read_records`、`entries`。用明确核心表和按 kind 分类的结构化扩展记录支持人物、关系、生词、字体、AI 服务 / 问答 / 提示词、主题方案、PDF 标注、阅读轮次、音频进度、同步记录与资料修改建议。没有机械复制原应用的 52 张表。

正文存为章节 JSON；原 PDF 二进制单独存为 BLOB，不混在元数据中。书架查询只读取摘要、章节标题 / 长度缓存和必要封面，打开书籍时再加载正文和资源。MCP 搜索依次加载书籍，避免同时读取整个书库。PDF 字节在页面生命周期内只解码一次。

笔记保留原文摘录和章节 / 字符位置。净化、间距、断词和简繁转换均构造显示文本到原文的偏移映射。章节编辑在事务中重算长度 / 摘要，优先找回原摘录位置，否则将锚点限制在新章范围；不会删除原摘录。

Android 默认 SQLCipher，随机密钥保存到平台安全存储。首次升级读取旧数据库、恢复到加密库，核对所有持久化表，写入加密恢复快照后再移除旧明文库。升级失败保留原数据库。书库锁是独立 UI 身份验证，并限制截图 / 后台缩略图；不等同于对每次 SQL 查询做生物识别。

备份在事务中取一致快照，恢复先验证数据，再单事务替换；失败回滚。新增小时统计，旧记录 hour=-1 不猜测历史时段。网盘恢复保留恢复后的阅读配置，并保留本次用户使用的同步连接配置。

## 阅读与性能

TextPainter 按实际样式和系统缩放分页，UTF-16 边界避开代理对。长篇文字导入时分为有界虚拟章节，阅读页保留最多三份布局缓存。双页布局使用两列真实分页宽度；翻页步长与当前布局一致。SelectableText 的长按 / 拖选保留，短点击由指针观察器处理，双击不会额外翻页。

OpenCC 原始词典来自 BYVoid/OpenCC，随附其许可证；使用最长词组匹配。英文断词来自 hyphenatorx 的英语模式。标点压缩依赖字体 `palt` 能力，不声明完整中文悬挂标点算法。

卷页使用真实页面快照和运行时 fragment shader，纸背 / 光影为视觉模拟。雨 / 雪是 Flutter 自绘动画，未声称还原原报告的 OpenGL 实现。阅读正文保持原生可选文字，不用图片替代。

## 网络与人工检查

HTTP 请求默认 HTTPS、关闭重定向、限制响应大小和超时；第三方凭据保存在安全存储。AI 只发送用户触发的所选摘录、当前章节（最多 3 万字符）或书架概览，界面明确范围。

MCP 默认关闭、只绑定 loopback，验证令牌、Host、Origin、协议版本和会话；限制请求大小、会话数与每会话请求次数。客户端可以提交资料修改建议，不能直接改书库；应用时校验资料是否变化，避免覆盖人工修改。离开工具箱或进入后台关闭服务。

Wi-Fi 传输仅提供已加密快照下载，随机链接令牌、最多三次、十分钟失效。关窗口 / 进后台 / 离开工具箱均停止，不提供目录列表或修改接口。

云盘目前是手动快照传输，不包含分布式增量同步、冲突合并或 OAuth 生命周期管理。范围详见功能对照表。

## 0.3.0 界面与资料补充

`home_dashboard.dart` 根据摘要与真实统计生成首页，卡片顺序用 `home.sections` 保存，不存伪造目标成绩。`appearance.dart` 统一应用主题与文字缩放，阅读配色继续独立。`tool_catalog.dart` 对实际工具动作分组 / 搜索。`statistics_period.dart` 使用自然日、周一开始的一周、月、年边界，支持闰年和历史切换。

`facets.dart` 统一标签拆分与名称校验；`library_collections.dart` 提供独立管理入口。新增 `facets` entries 保存空分组。`assignFacet` / `renameFacet` 在数据库事务中只更新资料列，保留全文、二进制源、笔记、进度和其他资料；不存在的书籍使整批回滚。标签为多值，分类 / 书单 / 作者为单值，尚无复杂层级关系。

`share_card.dart` 实现四种有实际数据的 PNG 卡片，日期来自当前日期，文字上限按 Unicode 码点截取。保存 / 分享之前等待界面完成绘制。主题选择保存在设置中。新增功能继续使用 schema 3 / backup version 2，无新数据库列。

隐私层在设置读取期间和锁定状态使用 Offstage 保留导航状态，同时隐藏绘制、触控和辅助功能内容；初始化时再次应用 Android secure 标记。原生身份验证仍需要设备回归。

## 0.3.1 热力图

`reading_heatmap.dart` 从已有按日秒数生成半年 / 全年自然日范围。星期按周一对齐，天数差使用 UTC 日历分量，生成单元格使用本地自然日构造器，避免夏令时错位。未来与范围外的数据不参与颜色、总时长或连续天数。七档采用固定秒数阈值，不随极值改变。

图表通过 CustomPainter 绘制；同一坐标模型处理点击、长按和辅助功能语义。全年横向滚动到当前日期附近，年份可回溯至 1970，不能进入未来年份。月份字体沿用应用 Roboto 字体族与系统中文回退。没有新增数据库结构、自动生成记录或导入原截图素材。

0.3.1 的 ARM64 包使用 pubspec 版本码 4，加上 Flutter 的 ABI 偏移后为 2004，高于该设备原包的 2003。通用包草案未发布；用户要求暂停上传，改为 ARM64 单架构，并通过 `packaging.jniLibs.useLegacyPackaging = true` 压缩原生库。安装时由 Android 提取库，二进制及 ELF 对齐不改变。压缩缩小下载，不能保证同比例减少安装占用。

## 0.3.2 应用形象

`branding.dart` 集中定义版本号、标记、封面、设置页应用卡片及中文关于弹窗。封面比例 2.6:1；首页与书架复用同一资源，避免重复打包。关于弹窗保留开源许可入口，正文只描述应用用途与本机数据。

Android 清单引用 `@mipmap/ic_launcher`，API 26 起使用前景位图、14dp inset 与黑色背景组成的自适应图标，旧设备使用五种密度 PNG。启动背景沿用同一标记，无额外等待时间。应用图案使用用户选定的白绿叠页设计，去掉外围框并适配横幅。pubspec 精确列出在用 WebP，排除旧横幅；原图与提示词在本机交付目录留存。版本更新为 0.3.2+5，ARM64 版本码为 2005，继续使用原签名和压缩原生库打包。

## 0.3.3 日历与周历布局

`HeatmapSpan.month` 按自然月构建范围，默认本月。复用周一对齐的数据模型，将周列转成四至六行、七列纯色方格；格子不显示日期数字，今天以小圆点标记，选中后在下方显示日期与时长。支持历史月份和跨年，按钮限制 1970 年以前及未来月份。日期使用 Material / InkWell、完整日期的语义标签与提示，未来日期禁用，摘要继续排除未来或范围外记录。

半年 / 全年每次显示整数个周列：格子宽高一致且边长至少 20dp，剩余月份横向浏览。初始滚动落在整周边界；ScrollEndNotification 在停止后就近吸附一周。画布跳过越过视窗边界的残格，并在最左可见周补画月份标记。窗口尺寸变化重新计算列宽和位置。

统计 ListView 使用独立 PageStorageKey，避免首次进入继承设置页偏移；去掉页内重复大标题，标题、日期范围、图例、选日与摘要居中。版本为 0.3.3+6，ARM64 版本码 2006，原签名和压缩原生库配置保持。
