## 数据

Schema 3：`books`、`notes`、`settings`、`read_records`、`entries`。用明确核心表和按 kind 分类的结构化扩展记录支持人物、关系、生词、字体、AI 服务 / 问答 / 提示词、主题方案、PDF 标注、阅读轮次、音频进度、同步记录与资料修改建议。没有机械复制原应用的 52 张表。

正文存为章节 JSON；原 PDF 二进制单独存为 BLOB，不混在元数据中。书架查询只读取摘要、章节标题 / 长度缓存和必要封面，打开书籍时再加载正文和资源。MCP 搜索依次加载书籍，避免同时读取整个书库。PDF 字节在页面生命周期内只解码一次。

笔记保留原文摘录和章节 / 字符位置。净化、间距、断词和简繁转换均构造显示文本到原文的偏移映射。章节编辑在事务中重算长度 / 摘要，优先找回原摘录位置，否则将锚点限制在新章范围；不会删除原摘录。

Android 默认 SQLCipher，随机密钥保存到平台安全存储。首次升级读取旧数据库、恢复到加密库，核对所有持久化表，写入加密恢复快照后再移除旧明文库。升级失败保留原数据库。书库锁是独立 UI 身份验证，并限制截图 / 后台缩略图；不等同于对每次 SQL 查询做生物识别。

备份在事务中取一致快照，恢复先验证数据，再单事务替换；失败回滚。新增小时统计，旧记录 hour=-1 不猜测历史时段。网盘恢复保留恢复后的阅读配置，并保留本次用户使用的同步连接配置。

## 阅读与性能

TextPainter 按实际样式和系统缩放分页，UTF-16 边界避开代理对。长篇文字导入时分为有界虚拟章节，阅读页保留最多三份布局缓存。双页布局使用两列真实分页宽度；翻页步长与当前布局一致。SelectableText 的长按 / 拖选保留，短点击由指针观察器处理，双击不会额外翻页。

OpenCC 原始词典来自 BYVoid/OpenCC，随附其许可证；使用最长词组匹配。英文断词来自 hyphenatorx 的英语模式。标点压缩依赖字体 `palt` 能力，不声明完整中文悬挂标点算法。

卷页使用真实页面快照和运行时 fragment shader，纸背 / 光影为视觉模拟。雨 / 雪是 Flutter 自绘动画，未声称还原原报告的 OpenGL 实现。阅读正文保持原生可选文字，不用图片替代。

## 网络与人工检查

HTTP 请求默认 HTTPS、关闭重定向、限制响应大小和超时；第三方凭据保存在安全存储。AI 只发送用户触发的所选摘录、当前章节（最多 3 万字符）或书架概览，界面明确范围。

MCP 默认关闭、只绑定 loopback，验证令牌、Host、Origin、协议版本和会话；限制请求大小、会话数与每会话请求次数。客户端可以提交资料修改建议，不能直接改书库；应用时校验资料是否变化，避免覆盖人工修改。离开工具箱或进入后台关闭服务。

Wi-Fi 传输仅提供已加密快照下载，随机链接令牌、最多三次、十分钟失效。关窗口 / 进后台 / 离开工具箱均停止，不提供目录列表或修改接口。

云盘目前是手动快照传输，不包含分布式增量同步、冲突合并或 OAuth 生命周期管理。范围详见功能对照表。
