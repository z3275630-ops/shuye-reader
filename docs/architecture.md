# 设计说明

## 从分析资料学到的设计

| 分析资料中的思路 | 书叶 0.1.0 的实际实现 |
| --- | --- |
| 阅读引擎与薄平台壳分离 | Flutter 业务层 + 模板 Android Activity；无业务逻辑塞入原生壳 |
| 结构化数据与轻量设置分层 | SQLite books / notes / read_records / settings；当前规模不复刻 52 张表 |
| 设置点分命名与迁移标记 | `reader.fontSize` 等键及 `_migration_seed_v1_completed`；删掉示例后不再自动补回 |
| 中文排版 + 智能分章 | 中西文间距、字体度量分页、自定义分章；专业标点压缩与连字符列为待办 |
| 净化规则保留用户控制权 | 只隐藏匹配整行，不改原文；位置映射让笔记与进度保持原文锚点 |
| 阅读记录独立保存 | 前台时间采样，本地按日聚合，热力图据实显示 |
| 用户拥有自己的数据 | 无账号、无后端、手动 JSON 备份及 Markdown 笔记导出 |
| 模式变化应说明代价 | 导入格式限制、备份替换、删书连带数据、不同签名安装边界均在界面或文档说明 |

## 数据模型

`books` 按文件 SHA-256 唯一，存储结构化章节 JSON、元数据及原文字符偏移。

`notes` 外键关联书籍，保存章节、原文偏移、摘录、评论和创建时间。删书使用外键级联，同时移除其笔记与阅读记录。

`read_records` 保存书籍、当地日期与秒数。应用进入后台或退出阅读页时记录，弹窗期间暂停采样。

`settings` 保存命名设置和种子数据迁移标记。数据库 schema 版本为 1，为后续迁移留出入口。

导入在 Dart isolate 中解析，界面不会承担文件解码工作。应用内只保存解析后的章节与可用封面，不保留原始 EPUB 包，因此第一版不能重新导出 EPUB 原文件。

备份使用同一事务获取一致快照；恢复先验证，再在单个事务中替换全部数据，任何插入错误自动回滚。

## 阅读位置

显示文本与原文分离：净化隐藏行、自动增加中西文空格时，每个显示字符映射回原始偏移。书籍进度和笔记锚点保存原始偏移，避免规则修改后跳到错误段落。

分页通过 TextPainter 测量实际字体、宽高和系统字体缩放，以二分搜索寻找页面边界；每次测量最多 5000 个 UTF-16 单元。候选边界先修正代理对，避免截断 emoji 时引擎错误返回单行高度。当前翻页直接切换文本，无 GPU 卷页动画。

## 后续路线

1. 真机回归：不同厂商的文件选择器、长篇小说导入、系统字号、旋转、后台恢复。
2. EPUB 插图、目录标题、脚注与更完整的排版；阅读引擎的段落样式和性能缓存。
3. 本地 PDF 阅读与标注，独立文件存储与更细粒度章节表迁移。
4. 密码保护 / 加密备份与数据库，再设计 WebDAV 同步的冲突、epoch 与迁移约定。
5. AI 服务端代理或安全密钥方案及可审阅的书库操作计划，之后考虑 MCP。

以上是后续方向，不是已经上线的功能。原报告的 GPU 性能、隐私、付费等推断不作为本实现的事实证明。
