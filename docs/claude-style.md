# 书叶 Android · Claude 风格

本轮目标是学习 Claude 的视觉与交互结果，用已有 Flutter 控件改善书叶。社区项目是参数参考，录屏聊天是方向大纲；不把参考项目的技术栈、商标、账号接口或维护指令带入书叶。

## 参数来源与取舍

- [Claude-Design-System](https://github.com/5j54d93/Claude-Design-System/tree/2f021019796fe714f18a3d5921373df4ad475533)：读取颜色、排印、形状、动效、组件章节及来源附录。该资料分析的是 claude.ai 应用界面和官网；采用应用界面的参数，手机布局另作适配。它提供的应用主底色为 `#F8F8F6` / `#1F1F1E`，主文字 `#121212`，Clay `#D97757`，灰色选中态、黑白主按钮、20px 输入卡和短时反馈有明确的组件说明。
- [SwiftUI ClaudeDesignSystem](https://github.com/viewer12/ClaudeDesignSystem/tree/f70eda1db9ddf73c7482a1d3670f531290578540)：借鉴系统字体、字体缩放、语义颜色和组件分层的适配方式；这是社区的原生风格实现，不是官方 Android 参数。书叶仍用 Flutter，不安装该包。
- [Claude 官方 Android 商店截图](https://play.google.com/store/apps/details?id=com.anthropic.claude)：核对中性底色、无衬线操作文字、衬线内容、轻卡片与灰色筛选。商店图片是经过排版的展示图，不能证明动态时序或精确尺寸。
- Mozaika、Duply 和 jcmrs 的网页结果作为交叉参考；它们之间的主色、字体和年代存在差异，未机械混用。Claudio 重建项目没有提供完整的应用视觉主题，未作为字号、配色或动效参数来源。

## 在书叶中的落地

| 项目 | Flutter 实现与手机适配 |
| --- | --- |
| 底色与层级 | 暖灰页面、浅色白卡片、深色炭灰卡片；正文、辅助文字、边框各自有语义颜色。主色少量用于强调，焦点和文字选取使用蓝色。 |
| 字体 | 界面使用已有系统无衬线字体；欢迎语、面板大标题和助手回答使用系统衬线。没有打包 Anthropic 字体。中文实际字形由 Android 提供。 |
| 字号 | 大标题 24 / 28 / 32dp；顶栏 19dp；列表与控件 14–15dp；助手输入与回答 16dp、1.5 行高。全部继续支持系统与应用字号缩放。 |
| 形状 | 按钮 / 表单 12dp，卡片 16dp，助手输入卡 20dp，弹窗 / 底部面板 24dp；书封仍为 8dp。以约 0.5–0.7dp 的边线与底色分层，取消书封厚阴影。 |
| 按钮 | 主操作黑白实底，次操作细框，取消 / 辅助操作无底；保留至少 44dp 的视觉高度及 Flutter 的触控与语义处理。 |
| 设置 | 四组阅读控制、滑杆数值标签、难懂选项的短说明；应用外观实时文字预览；书架用前三本藏书展示紧凑预览，空库明确提示，未添加假书。 |
| 助手 | 原生 TextField / Card / FilledButton 组成底部输入卡，上方回答可选择、滚动；提示词横向滚动，键盘弹出时收起提示区以保留输入和发送。范围说明和应用前检查继续保留。 |
| 动效 | 原生按钮颜色反馈 100ms；外观、书架、排版、阅读控制、首页布局、助手面板和共用表单入场 200ms、退场 150ms。系统关闭动画时这些面板使用无动画。没有新动画库、持续装饰动画或模糊层。 |

这些是书叶的 Android 适配值，不声称是对 Claude 原生 APP 的逐像素还原。个人阅读纸色、字体、位置、笔记、音频和隐私设置沿用原数据；配色调整不修改书籍内容。

## 验证与成本

对常用文字 / 表面组合和强调文字验证至少 4.5:1 对比度；检查 320dp、1.5 倍字号、浅深主题及键盘遮挡。安装包体积与截图结果见 [0.3.7 验证](verification-0.3.7.md)。预览由实际 Flutter 控件用 Windows 字体渲染；尚无 Android 手机实测。

没有新增依赖、字体或图片，锁文件不变。大书存储、恢复安全和后台音频等未完成事项继续由 [协作衔接表](prd/review-2026-10-05.md) 跟踪；本轮先完成用户要求的风格调整。
