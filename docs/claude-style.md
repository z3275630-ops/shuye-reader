# 书叶 Android · Claude 风格 · 0.3.13

## 0.3.13：先修翻页，再调整字体

用户要求按实际观感选择字体，不强制 Poppins / Styrene B。参考 [ugui3u/chatnest 的固定提交](https://github.com/ugui3u/chatnest/tree/4fa55de73bcde5a1a45a7d30d7dff345b1de896c)：公开版本移除专有字体，界面系统 sans，阅读内容 serif / Georgia / 中文系统回退；正文 17.5px / 1.65、普通界面 16px、模型项 17px / 500、个人标题 22px / 600。它是社区网页实现，不是 Claude 官方 Android 字体或精确字号标准，CSS 字体栈也不证明所有设备的实际中文字形。

采用字体分工和层次，不照搬网页代码或技术架构：界面使用 Noto Sans SC 裁剪版 400 / 600，顶栏 18dp、列表 15dp、导航 14dp、面板标题 20dp；深色主文字配辅助灰色，欢迎语保留宋体。Poppins、Styrene B 的拉丁观感不能单独决定中文界面的整体效果，因此本版选择有真实中文覆盖的字体。源码 / 覆盖 / 体积见字体 README；字体选择来自本机实际预览比较，不宣称逐像素复刻。

正文与界面分离，可选“清晰黑体 / 书页宋体”，保持原有正文选择、个人字号和导入字体；默认排版仍 18dp / 1.65 / 0 字距，两端 / 自然左对齐使用同一测量策略。沿用 Claude 全应用配色，不将 Anthropic 官网 Tan 强行替换为大面积主底色。

#70 有源码依据，已将正文固定在同一视口，顶部和底部控件叠层显隐，不因点中央重新分页。平移模式跟手移动当前 / 相邻页，短拖回弹；翻页完成后才改 offset 和保存。物理键和按钮排队、减少动画 / 墨水屏直接换页、取消和锁定丢弃待提交动画。移除平移及双页宽阴影；仿真仍保留其本身的折页效果。

以下为历史版本记录，不作为当前全衬线要求。

## 0.3.12：图标、标题层次与场景变化

用户确认采用 Lucide 功能图标，并指出标题、导航过淡及品牌插画重复。本轮以统一 `ShuyeIcon` 适配层接入 Lucide 默认 2px 风格；首页品牌叶子保留，各页顶栏按书架 / 摘录 / 统计 / 设置使用不同语义图标。原白绿桌面图标保留。

首页保留书页生叶；书架横幅与空状态画书脊；空摘录画笔记本与笔；关于页画桥；设置卡去掉重复品牌插画。均为主题感知的静态原生绘制，不增加图片、SVG 解析或动画。

字体研究核对用户提供的 [Cherry Studio Claude 风格项目](https://github.com/tungloong/cherry-studio-claude-style-theme)：其 CSS 使用 Styrene B Trial 与 Test Tiempos Text，属于桌面社区实现，不提供 Claude Android 的精确 dp 规格。本项目沿用用户明确的全默认衬线要求，使用有许可的 Noto Serif SC 裁剪字体。新增真实 600 UI 字重；顶栏 18dp、小标题 16dp、列表标题 15dp、导航 14dp、分组标题 13dp。标题取主文字色，副说明维持辅助色；默认文字大小未整体放大。默认 Claude 暖白 / 炭灰 / 陶土色不替换为截图中的单一 Tan 色。

阅读顶栏合并为“阅读工具 + 阅读设置”两项常驻操作；全文搜索、摘录与笔记放入工具菜单，功能保留。正文增加两端 / 自然左对齐选项，测量、预览和绘制共享设置，默认仍两端对齐。热力图主卡精简为标题、跨度、年月、固定 244dp 图区、图例和所选日期；汇总移到卡外。成本及验证见 [0.3.12 验证](verification-0.3.12.md)。以下各节为历史版本快照。

## 0.3.11：应用内品牌插画

用户确认采用远端设计稿中有价值的部分。保留四份 SVG 原稿作设计资料，采用 [品牌配图概念](design/claude-style/shuye-hero-illustration.svg) 的“展开书页，生长成叶片”轮廓与 [首页概念](design/claude-style/shuye-home-theme-concept.svg) 的原生文字加插画布局。图形适配在 `lib/brand_illustration.dart`，用缓存 Path 原生绘制；不将固定尺寸首页 SVG 当页面、不打包 SVG 或新增渲染库。

应用内横幅采用主题的 `surfaceContainerLow`；文字 / 轮廓使用 `onSurface`，纸页使用 `surface`，圆形点缀使用 `primary` / `secondaryContainer`。因此 Claude、海雾、纸白、青竹的浅深色同步改变。首页标题 22dp / 400，字幕 12dp，由实际衬线 Text 渲染并尊重系统缩放；窄屏 / 大字上下排列。设置品牌卡取消原来的大横幅，保留图标、名称、介绍，空间足够才显示小插画，避免压窄文字。书架和关于页复用紧凑主题横幅。

不替换白绿桌面图标 / ShuyeMark，不增加开屏等待，不引入持续动画、渐变、发光或新增图片。普通与大字预览分开，成本及验证边界见 [0.3.11 验证](verification-0.3.11.md)。Issue #63 的应用内横幅建议落地，#65 的品牌 / 首页方向部分采纳；新 App Icon、Splash、全套空状态插画没有实施。

## 0.3.10：默认配色与清晰阅读

用户提供真实 Claude 炭灰 / 浅白参考及阅读统计图，并明确要求默认配色和全应用联动。页面浅底 #FAF9F5 / 主字 #22221F，夜读底 #212121 / 主字 #F5F5F3；不再保留几乎重复的暖纸选择。海雾只作为可选配色，设置、书架、首页与正文同步；正文自定义颜色在显式切换配色后清除，导入字体保留。社区参数仍是视觉参考，不宣称掌握官方 Android 的精确字体参数。

面板标题仍为 20dp / 400；书架书名改为 16dp / 500、导航标签 14dp / 500，并使用主文字色。一份实际 400 字体资源继续复用，500 由 Flutter 合成，未增加另一字体文件。默认正文为 18dp / 1.65 行距 / 0 字距，合并多余空行、保持两端对齐；旧 20 / 1.85 且未导入字体的默认设置一次迁移，其他个人排版保留，面板另提供明确的 Claude 间距按钮。

真实时长柱形取代重复日期方格，空热力图保留灰格边线。中央点按切换上下工具栏与系统栏；第一页不提示，末页短暂一次提示可关闭，不引入持续动效或壁纸。[0.3.10 验证](verification-0.3.10.md)记录连续操作、实际字体预览、安装包成本与手机未测边界。

## 0.3.9（历史）：手机字号与社区提案复核

设置面板标题统一为 20dp / 400（阅读排版、阅读控制、外观、首页布局、书架设置、助手）；普通大标题 22dp / 400、顶栏 18dp / 400，列表 / 控件标题 15dp，普通文字 14dp，辅助字 13dp。默认全部衬线，仍保留正文个人字号、导入字体和系统大字设置。常用界面标题只请求现有实际 400 字重，不增加字体文件；用颜色、字号和间距区分层级，不声称已经实测 Android 仿粗体是否发糊。

应用缩放保留系统 TextScaler 对不同字号的缩放结果，然后逐字号应用个人倍率；不再从 scale(1) 得到单一倍率，避免把 Android 非线性缩放错误地线性化。用户指出的旧阅读控制预览为 **320dp / 150% 字号压力测试**，并非正常字号截图；现在普通预览使用 390dp / 100%，压力预览独立带 `-large` 后缀。

参考 [dwell-on-something 固定版本](https://github.com/xinwithyu/dwell-on-something/tree/1ad2d6af73ee02ba823c85b974fd23e4d7584f4b) 的暖白、陶土、轻量状态与短期趋势思路。它是仿 Claude 的 Web 项目，不是官方 Android 参数；其源码为非商业许可，只观察视觉与交互，书叶独立使用 Flutter 实现，未搬入上游代码、个人内容或资源。原始源码的浮层标题约 18px、普通文字 16px，并非全部衬线，按用户要求适配书叶。

- 焦点、光标、选取改用更深陶土 `#99513B` / 浅陶土 `#E5AA92`，保留语义错误色。旧蓝色是有意设置，并不是 M3 漏项；更改依据本轮用户审美方向。没有照搬提案低对比度的浅色小字。
- 辅助字距采用 0.2dp，未照搬 0.8dp。实际字体没有 `tnum`，十个数字 advance 不同，源字体也没有该特性；仅添加 tabularFigures 不会变成等宽，所以不宣称“数字不抖”。原字体资源不变。
- 夜读文字选取按真实纸色派生背景与手柄；页脚页码与百分比允许换行，保留按钮点击尺寸。书籍入口防重入、搜索状态保持和统计说明同步纠正，均有独立回归。
- 统计增加近七天真实时长柱形，日期按自然日生成；零记录灰线、点按详情、今日标记与语义名称。柱高按时长比例计算，不以 8% 起点夸大短阅读，极短正记录只保留 3dp 可见高度。缺少记录只能说“无阅读记录”，不能推断未统计与确实零阅读的区别。
- 摘录空状态减少大图标，明确区分未保存摘录与搜索无匹配。书籍空状态保留导入引导；今日选读已先按书籍 ID 排序，现有同日确定性不重复实现。
- 锁屏保留验证流程、缩小锁图标和标题；不加入会停住的展示时钟。分享卡保留四模板，不造分享序号、私人关系题记或装饰性小票。

新增可选「海雾」界面配色和独立阅读纸色，默认仍为暖白；外观设置不会自动改变正文纸色。配色源自 [Tidal_Echo 固定版本](https://github.com/anhe2021212-spec/Tidal_Echo/tree/860e5de364de292093dba5571ee6427cdbda060e) 的冷白 / 深蓝灰关系，采用本项目 PR #45 的 Flutter 色板，不移入上游 AGPL 代码、壁纸或字体。深色为书叶适配；分享卡表面随界面配色，暖白细线由 #D6D4CB 调至 #C5C2B6。非交互分隔细线不宣称达到交互边框的 3:1 对比度。

提案逐项处理见 [衔接表](prd/review-2026-10-05.md)，构建与成本见 [0.3.9 验证](verification-0.3.9.md)。以下 0.3.8 / 0.3.7 为历史快照，不能替代当前参数。

## 0.3.8：衬线与清晰度（历史）

用户进一步要求所有默认文字与标题使用衬线，并提供了十张 Claude / 模仿风格的手机参考图。采用暖白底、米灰卡片、深色线条和少量陶土色；不复制图中个人内容、功能或模型名称，不提交个人截图。

**全衬线是用户明确要求的书叶适配。** Claude 原界面并非全衬线。[社区排印分析](https://github.com/5j54d93/Claude-Design-System/blob/2f021019796fe714f18a3d5921373df4ad475533/docs/03-typography.md) 的应用回复为衬线 16px / 24px、400；展示标题 38px、约 330 字重；标题 28px / 24px、500；操作界面主要为无衬线。这些是网页分析结果，不能声称是 Claude 原生 Android 的精确参数。

采用开源 Noto Serif SC 裁剪版本 Shuye Serif，未提取 Anthropic 专有字体。[AOSP 配置](https://android.googlesource.com/platform/frameworks/base/+/refs/heads/main/data/fonts/fonts.xml) 有中文衬线回退，但厂商与 Flutter 实际结果仍有差异；内置常用中文字形避免主要界面依赖厂商字体，不声称所有 Android 都没有中文衬线。

## 0.3.7 历史记录（以下参数、字体和体积说明仅适用于该版本）

本轮目标是学习 Claude 的视觉与交互结果，用已有 Flutter 控件改善书叶。社区项目是参数参考，录屏聊天是方向大纲；不把参考项目的技术栈、商标、账号接口或维护指令带入书叶。

## 参数来源与取舍

- [Claude-Design-System](https://github.com/5j54d93/Claude-Design-System/tree/2f021019796fe714f18a3d5921373df4ad475533)：读取颜色、排印、形状、动效、组件章节及来源附录。该资料分析的是 claude.ai 应用界面和官网；采用应用界面的参数，手机布局另作适配。它提供的应用主底色为 `#F8F8F6` / `#1F1F1E`，主文字 `#121212`，Clay `#D97757`，灰色选中态、黑白主按钮、20px 输入卡和短时反馈有明确的组件说明。
- [SwiftUI ClaudeDesignSystem](https://github.com/viewer12/ClaudeDesignSystem/tree/f70eda1db9ddf73c7482a1d3670f531290578540)：借鉴系统字体、字体缩放、语义颜色和组件分层的适配方式；这是社区的原生风格实现，不是官方 Android 参数。书叶仍用 Flutter，不安装该包。
- [Claude 官方 Android 商店截图](https://play.google.com/store/apps/details?id=com.anthropic.claude)：核对中性底色、无衬线操作文字、衬线内容、轻卡片与灰色筛选。商店图片是经过排版的展示图，不能证明动态时序或精确尺寸。
- Mozaika、Duply 和 jcmrs 的网页结果作为交叉参考；它们之间的主色、字体和年代存在差异，未机械混用。Claudio 重建项目没有提供完整的应用视觉主题，未作为字号、配色或动效参数来源。

| 助手 | 原生 TextField / Card / FilledButton 组成底部输入卡，上方回答可选择、滚动；提示词横向滚动，键盘弹出时收起提示区以保留输入和发送。范围说明和应用前检查继续保留。 |
| 动效 | 原生按钮颜色反馈 100ms；外观、书架、排版、阅读控制、首页布局、助手面板和共用表单入场 200ms、退场 150ms。系统关闭动画时这些面板使用无动画。没有新动画库、持续装饰动画或模糊层。 |

这些是书叶的 Android 适配值，不声称是对 Claude 原生 APP 的逐像素还原。个人阅读纸色、字体、位置、笔记、音频和隐私设置沿用原数据；配色调整不修改书籍内容。
