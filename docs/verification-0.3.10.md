# 0.3.10 验证 · 2026-10-06

正式版本 **0.3.10+13**，ARM64 版本码 **2013**。本轮针对用户截图指出的主题联动、正文密度、阅读工具栏、提示与统计可读性修复；主 Agent 直接提交 main，没有另开 PR。

## 实现与回归

- 默认使用 Claude 暖白 / 炭灰，全应用与正文联动；合并重复的暖纸选项。海雾反序列化白名单补全，选择后回首页 / 书架、重新进入阅读及重启都保持配色。显式切换配色清除正文自定义颜色；未切换时保留原自定义颜色。
- Claude 页面浅底 #FAF9F5、主字 #22221F；夜读 #212121 / #F5F5F3。书架书名 16dp / 500、底栏 14dp / 500，均使用主文字色。仍只有一份 400 字体资源，请求 500 字重由 Flutter 合成，没有新增真正的 500 字体文件。
- 默认正文 18dp、1.65 行距、0 字距、合并多余空行，保留两端对齐及原文位置映射。只有尚未迁移、排版恰为旧默认 20dp / 1.85 且没有导入字体的设置自动收紧；其他个人排版和导入字体保留。排版面板提供 Claude 间距按钮。
- 点按正文中央切换顶栏 / 页脚；首末边界不再触发翻页快照。第一页没有提示，末页提示 900ms、可关闭、同一次抵达只显示一次。组件回归实际连续滑动验证去重与消失，不靠缩短测试等待掩盖问题。
- Android 通过 WindowInsetsControllerCompat 隐藏 / 显示系统状态栏和导航栏，允许手势临时唤回；覆盖页面、返回与退出时恢复对应状态。适配 target SDK 36，未通过降低 SDK 绕过限制。Android 原生代码构建通过；**没有连接手机，系统栏实效仍待真机回归**。依据 [Android 沉浸文档](https://developer.android.com/develop/ui/views/layout/immersive)；Flutter 的 [SystemUiMode 说明](https://api.flutter.dev/flutter/services/SystemUiMode.html) 不能作为 API 36 上 immersiveSticky 生效的依据。
- 未阅读日期仍绘制完整灰格与边线，浅深 / 半年 / 全年可见。统计去掉重复的 1–31 / 0分方格与 0–23 空时段方格；按周 / 月 / 年显示真实时长柱形和明确日期、分钟单位及点按详情，空数据只显示说明。小时记录显示 08:00–09:00 等时段及真实分钟数，未记录时不造柱图、速度或 WPM。
- 设置损坏保留原设置副本、书籍及笔记，恢复默认并锁住书库，明确说明原因。云盘下载与本地恢复刷新工具箱持有的同一设置对象，后续保存不写回旧值。
- 备份先提交活跃正文 / PDF 秒数并排空计时队列；恢复前排空旧队列，恢复事务期间暂停计时、拒绝新记录 / 备份并发进入；成功后旧阅读页不再写回时长及进度。恢复失败解除保护，不递增书库代次。此项没有实现自动恢复点或大书库低内存迁移。
- 恢复日期要求真实有效，拒绝二月三十一日、十三月、零年份并保留原库；合法闰日和未来日期保留。PDF 延迟回调检查 mounted；均衡器异步回调检查面板仍在；封面超限 / 读取失败可见提示，入库成功才改变显示；平台错误不再阻断同次启动的深链接。
