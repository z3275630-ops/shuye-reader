# 验证记录 · 0.3.4 · 2026-10-05

## 实现与验证

- 全应用共用 applicationTheme：弹窗、底部面板、菜单、按钮、输入框、标签、列表、提示、卡片、文字层级与底栏。浅 / 深主题缓存，不改变用户正文排版设置。
- 105 处应用层 Icon 调用使用 ShuyeIcon；覆盖现有全部 74 个图标标识，图形采用统一线宽并缓存 Path，未知的未来标识回退原生 Flutter Icon。修复受按钮 / 输入框约束时图形被拉大的问题，图形居中保持自身尺寸。
- 没有新增依赖、字体 / 图标包、图片资源或装饰性定时器、后台任务、持续动画与模糊叠层。pubspec.lock 与上版字节一致。新增唯一文本资源为项目 MIT 原文，在用户打开许可页时才加载。
- `dart format lib test`：42 个文件；`flutter analyze --no-pub` 无问题；`flutter test --no-pub --concurrency=1`：49 项通过，默认跳过 3 项可选预览测试。
- 新界面交互测试覆盖 320px、1.5 倍字号及浅深色下的导航、图标语义、约束下图形尺寸、弹窗输入与保存。现有导入、书库、阅读、笔记、备份、热力图、分享和工具测试继续通过。
- 3 项可选截图测试通过，生成 24 张 Flutter 控件预览，包括主要页面、月 / 半年 / 全年热力图和浅深色图标 / 弹窗预览。人工查看首页、书架、阅读设置、笔记编辑、工具箱、设置、关于、热力图和新增预览；截图为 Windows 字体的 Flutter 渲染，不是安卓真机截图，热力图彩色数据仅限测试。
- `flutter build apk --release --target-platform android-arm64 --split-per-abi --no-pub` 成功；保留压缩原生库。包名 dev.shuye.shuye_reader，版本 0.3.4、ARM64 split 版本码 2007，最低 API 24、目标 API 36。
